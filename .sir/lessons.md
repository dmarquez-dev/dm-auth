2026-11-20 20261120-0315-sir-bootstrap [harness] On this machine `gh` is installed at `C:\Program Files\GitHub CLI\gh.exe` but is on neither the Bash nor the PowerShell PATH the harness uses, so call it by full path; `gh event listen` returns HTTP 403 for this account, so wait on a PR by polling `gh pr view --json state`.
2026-11-23 20261123-0703-codebase-audit [project] This checkout runs `core.autocrlf=true` with no eol rule in `.gitattributes`, so `.sir/` files are CRLF in the working tree and LF in the blob: `.sir/backlog.md`'s four pre-session lines are 1066 bytes in the working tree and 1062 in the blob, and an editing agent can leave the whole working copy CRLF while the commit stays LF. A byte, hash or line-ending criterion must name the reading it measures (`git show <ref>:<path>` for the blob), and a CR-stripped prefix must strip the CR before taking the bytes.
2026-11-23 20261123-0703-codebase-audit [harness] In Git Bash, `git show <branch>:<path>` with a `/` in the branch name (`chore/codebase-audit:.sir/backlog.md`) is rewritten by MSYS path conversion and fails as an ambiguous argument, so pass a commit hash (`git show <sha>:<path>`) instead.
